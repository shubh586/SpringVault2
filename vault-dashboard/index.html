Integration Guide

1

Add the vault-client dependency

<dependency>
    <groupId>com.appvault</groupId>
    <artifactId>vault-client</artifactId>
    <version>1.0.0</version>
</dependency>
2

Configure vault connection

vault:
  url: http://localhost:8200
  token: ${VAULT_SERVICE_TOKEN}
  environment: dev
  secret-paths:
    - database/credentials
    - api/payment
  fail-on-error: false
3

Use secrets — Three options

Recommended @Value injection 

@Value("${database.credentials.password}")
private String dbPassword;

Custom @VaultSecret annotation 

@VaultSecret(path = "database/credentials", key = "password")
private String dbPassword;

Programmatic VaultClient bean 

@Autowired
private VaultClient vaultClient;

String password = vaultClient.getSecret("database/credentials", "password");
✓

That's it! No other code changes needed.

The vault-client library handles everything: fetching secrets before Spring initializes, caching, background refresh, and token authentication.
